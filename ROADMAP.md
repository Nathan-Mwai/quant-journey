# Quant Developer Roadmap

A quant developer writes the software that researchers and traders depend on:
pricing models, backtesters, data pipelines and trading systems.
The job is mostly software engineering, with enough maths and finance to
understand what the code is supposed to do.

Timings assume about 10 focused hours a week alongside university.

## Stage 1: Programming foundations (months 1-3)
- Python: variables, loops, functions, data structures, files, errors
- Tools: terminal, VS Code, Git, GitHub
- **Project:** a portfolio tracker that reads prices from a CSV file

## Stage 2: Data and statistics in code (months 4-6)
- NumPy, pandas, matplotlib
- Returns, volatility, correlation, regression (link these to your econometrics units)
- SQL basics
- **Project:** an analysis of real Nairobi Securities Exchange price data

## Stage 3: Computer science fundamentals (months 7-12)
- Data structures and algorithms, Big-O
- Object-oriented design, testing with pytest
- Linear algebra and probability, studied properly
- **Project:** an event-driven backtester, with tests

## Stage 4: Quant finance and C++ (year 2)
- Options, Black-Scholes, Monte Carlo simulation
- C++: memory, classes, the standard library, performance
- Concurrency and networking basics
- **Project:** an options pricing library in C++ called from Python

## Stage 5: Becoming employable (year 2 onwards)
- A clean public GitHub with 3-4 finished projects
- Interview practice: algorithms, probability puzzles, C++ questions
- Internships in software, data or risk are all useful stepping stones
